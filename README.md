<h2>Sobre o Projeto</h2>

<p>
Este repositório reúne os desafios que desenvolvo na plataforma 
<strong>Frontend Mentor</strong>, uma comunidade que propõe projetos práticos
baseados em layouts reais, ajudando a evoluir habilidades técnicas e visuais
no desenvolvimento Front-end.
</p>

<p>
Cada desafio é organizado em sua própria pasta e publicado online,
servindo como parte do meu <strong>portfólio de estudos e evolução</strong>.
</p>
